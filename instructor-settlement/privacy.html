개인정보처리방침

문서 버전: 2026년 9월 28일

출강정산은 개인 강사의 수업 기록과 센터 정산 명세를 연결해 차이를 확인하는 도구입니다. 위티앱스는 이 방침에 따라 앱 기록과 서비스 운영 정보를 처리합니다.

1. 기기에 저장되는 기록

센터 별칭, 계약과 적용 기간, 수업 기록과 선택 별칭, 명세 행, 연결 관계, 확인한 조정·공제, 입금·배분, 정산 이력은 기기의 앱 저장 공간에서 처리합니다. 회원가입, 자체 기록 서버와 자동 클라우드 동기화를 제공하지 않습니다. 이 기록을 분석 서비스나 고객지원에 자동 첨부하지 않습니다.

앱 잠금을 켜면 운영체제의 생체인증 또는 기기 잠금 인증 화면을 사용합니다. 지문·얼굴 원본과 기기 암호는 운영체제가 처리하며 앱은 인증 성공 여부만 받습니다. 앱은 생체정보 원본을 수집하거나 저장하지 않습니다.

2. 사용 분석과 오류 확인

Google Firebase Analytics와 Crashlytics를 사용해 기능 이용과 오류를 확인합니다. 앱 설치 단위 식별자, 기기·운영체제·언어 정보, 앱 버전, 세션과 화면 이용, 이벤트 발생 시각, 기술적인 오류 정보가 처리될 수 있습니다. 앱이 추가하는 분석 항목은 기능 선택과 성공·실패 상태, 앱·빌드 구분과 유료 이용 상태 등으로 제한합니다. 이 정보는 앱의 사용 흐름과 안정성을 개선하는 데 사용합니다.

마스킹된 IP 주소에서 추정한 대략적 지역과 스토어 인앱 구매·구독 사건의 상품 ID·상품명·가격도 자동 처리될 수 있습니다. 이 가격은 스토어 상품 가격이며 업무 기록에 입력한 금액과 별개입니다. 오류 진단에는 오류가 난 위치, 예외 종류·메시지와 당시 앱·기기 상태가 포함될 수 있습니다.

업무 기록에 입력한 이름, 날짜, 시각, 금액, 메모, 파일명, 가져온 자료와 클립보드 원문은 앱의 별도 분석 항목으로 보내지 않습니다. 분석 도구가 자동으로 기록하는 이벤트 발생 시각은 업무에 입력한 날짜·시각과 별개입니다. 앱에 광고를 게재하지 않으며 광고 개인화에 업무 기록을 사용하지 않습니다.

3. 구독과 구매 복원

결제는 Apple App Store 또는 Google Play에서 처리합니다. RevenueCat은 구독 상태 확인과 복원을 위해 익명 앱 사용자 식별자, 상품·거래 식별자, Apple 영수증 또는 Google 구매 토큰, 구매·갱신·만료·환불 상태를 처리합니다. 기기 종류·운영체제와 최근 앱 사용 시점도 처리될 수 있습니다. 앱은 카드번호나 은행 계좌 접속 정보를 받지 않습니다. 업무 기록을 구매 서비스로 보내지 않습니다.

4. 백업과 사용자가 선택한 공유

자체 백업은 사용자가 정한 비밀번호로 암호화합니다. 비밀번호를 잊으면 개발자가 백업을 해독하거나 복구해 드릴 수 없습니다. CSV 또는 PDF 내보내기는 암호화 백업과 다르므로 공유할 항목과 받는 곳을 확인해야 합니다.

Android에서는 앱 내부 저장소를 시스템 클라우드 백업과 기기 간 전송 대상에서 제외하도록 설정합니다. iOS에서는 앱 내부 데이터베이스와 앱이 만든 복구본에 시스템 백업 제외 속성을 적용하고 암호화 키를 이 기기 전용으로 저장합니다. 운영체제의 자동 백업·기기 이전·재설치로 기록이 복구된다고 보장하지 않습니다. 기기를 바꾸거나 앱을 다시 설치하려면 앱에서 직접 만든 비밀번호 암호화 백업 파일과 그 비밀번호가 필요합니다.

사용자가 파일 앱이나 공유 화면에서 직접 저장한 암호 백업·내보내기 파일은 선택한 저장소와 수신 앱의 설정·개인정보처리방침을 따릅니다. 개발자는 그 복사본을 원격 삭제하거나 자동 복구하지 않습니다.

5. 보관과 삭제

업무 기록은 사용자가 삭제할 때까지 기기에 보관됩니다. 설정의 전체 데이터 삭제로 지울 수 있습니다. 앱 안의 기록이나 앱을 삭제해도 사용자가 외부에 저장한 백업·내보내기 파일은 남을 수 있으므로 별도로 확인해야 합니다. 구독을 해지해도 기존 기록의 열람·수정·삭제·내보내기·백업·복원을 막지 않습니다.

분석·오류·구매 정보의 보관은 각 제공자의 처리 정책과 적용된 서비스 설정을 따릅니다. Crashlytics는 오류와 관련 식별자를 90일간 보관한 뒤 삭제 절차를 시작합니다. Google Analytics의 사용자·이벤트 보관 설정은 표준 집계 보고서의 보관과 다릅니다. 개인정보 문의나 삭제 요청은 아래 연락처로 보낼 수 있습니다. 요청 확인에 필요한 최소 정보만 요청하며, 기기에만 저장된 기록은 개발자가 조회할 수 없습니다.

6. 외부 처리 서비스

  • Google: 사용 분석과 오류 진단 — Firebase 개인정보 안내, Analytics 기본 수집 안내
  • RevenueCat: 구매 상태 확인과 복원 — RevenueCat 개인정보처리방침
  • Apple·Google: 스토어 결제, 구독 관리와 환불

위 제공자는 대한민국 밖의 서버에서 정보를 처리할 수 있습니다. RevenueCat은 미국의 Amazon Web Services 데이터 센터에 고객 데이터를 저장한다고 안내합니다. 앱 코드가 직접 추가하는 맞춤 분석 사건과 RevenueCat 요청에는 업무 원문을 넣지 않습니다. 분석·오류 도구가 자동 수집하는 자료는 위에 적은 항목과 각 제공자의 정책을 따릅니다.
